# ChallengeForIT

La rama `develop` contiene el código para revisión y corrección.

La rama `main` será usada para despliegue y producción.


Este repositorio contiene una aplicación básica de lista de tareas dividida en dos partes:

- [Backend (API REST) - Node.js + Express + Prisma (SQLite)]

- [Frontend (React + Vite + TailwindCSS)]
---

## Estructura del proyecto

- `Back/` - Código del backend con Express y Prisma como ORM, usando SQLite como base de datos.

- `Front/` - Código del frontend con React, Vite y TailwindCSS.

---

## Tecnologías usadas

- **Backend:** Node.js, Express, Prisma ORM, SQLite
- **Frontend:** React, Vite, TailwindCSS
